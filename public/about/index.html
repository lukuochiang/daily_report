关于科技互联网每日一报

一个静态、开放、可持续积累的科技资讯双语简报。

网站定位

网站每天从公开 RSS 与 API 采集全球科技、互联网、人工智能与开发者生态资讯，经过清洗、去重、分类和 AI 辅助整理后，生成中英双语日报。网站不包含数据库、后台服务或动态接口，所有页面均为静态 HTML。

数据来源

目前接入 TechCrunch、The Verge、Ars Technica、WIRED、InfoQ 中文、Hacker News（Firebase 公开 API）以及 GitHub Search API。GitHub 数据为基于搜索条件的近期高星仓库代理数据，并非官方 Trending 排名。每条新闻均保留原始来源与原文链接。

AI 整理方式

通过兼容 OpenAI 接口的 DeepSeek API 生成中英双语标题与摘要、分类、重要性评分、重点新闻和趋势分析。AI 仅依据原始标题与摘要工作，不编造事实；结果标注为“AI 整理”。当 AI 不可用或返回异常时，保留原始标题与原文摘要，并明确标注“原文摘要”，不会丢失整份日报。

更新频率与时间

GitHub Actions 于 UTC 22:30（北京时间次日 06:30）自动生成日报，并支持手动触发。定时执行可能排队延迟；所有页面时间均按北京时间（UTC+8）展示。

版权声明

本站仅提供新闻标题、链接与简短摘要，不转载媒体全文。原始新闻版权归原作者及发布媒体所有。本站 AI 生成内容仅供信息检索与阅读参考，请以原文为准。
